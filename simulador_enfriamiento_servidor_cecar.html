SECCIÓN 01

Planteamiento del Problema e Introducción

Gestión Térmica Crítica en Centros de Datos

En la Ingeniería de Sistemas moderna, la continuidad operativa de los servicios en la nube, bases de datos y servidores empresariales depende directamente de la estabilidad térmica de los centros de datos (Data Centers). El procesamiento continuo genera una elevada disipación de calor en los procesadores (CPU) y racks de servidores.

Cuando ocurre una falla temporal en el sistema principal de climatización, la temperatura del núcleo del servidor escala rápidamente hasta niveles críticos ($85\text{ }^\circ\text{C}$), amenazando la integridad física del silicio y provocando apagados de emergencia. Al activarse el sistema auxiliar de ventilación forzada, resulta indispensable predecir matemáticamente cuánto tiempo tardará el equipo en descender bajo el umbral operativo seguro ($35\text{ }^\circ\text{C}$ recomendado por ASHRAE).

Fundamento Físico-Matemático

Ley de Enfriamiento de Newton

Establece que la rapidez con la que cambia la temperatura $T(t)$ de un cuerpo respecto al tiempo es directamente proporcional a la diferencia entre su temperatura actual y la temperatura constante del medio ambiente $T_{amb}$:

$$\frac{dT}{dt} = -k(T - T_{amb})$$

El signo negativo indica que cuando $T > T_{amb}$, la derivada es negativa ($dT/dt < 0$), reflejando un decaimiento térmico exponencial hacia el equilibrio ambiental.

SECCIÓN 02

Formulación y Desarrollo Matemático Paso a Paso

2.1. Definición de Variables y Parámetros del Caso Base

$t$ Variable Independiente

Tiempo transcurrido desde la activación del enfriamiento (min).

$T(t)$ Variable Dependiente

Temperatura del núcleo del servidor en el instante $t$ (°C).

$T_{amb} = 22\text{ }^\circ\text{C}$ Parámetro Ambiental

Temperatura climatizada constante de la sala técnica.

$T_0 = 85\text{ }^\circ\text{C}$ Condición Inicial

Temperatura crítica registrada al iniciar contingencia ($t=0$).

$k = 0.055\text{ min}^{-1}$ Constante Térmica

Coeficiente de disipación por ventilación forzada.

PASO 1 • PVI

Problema de Valor Inicial

Sustituimos los parámetros del servidor en la EDO lineal de primer orden:

$$\frac{dT}{dt} = -0.055(T - 22), \quad T(0) = 85$$
PASO 2 • INTEGRACIÓN

Separación de Variables

Agrupamos diferenciales e integramos ambos lados de la ecuación:

$$\int \frac{dT}{T - 22} = \int -0.055\,dt \implies \ln|T - 22| = -0.055t + C_1$$
PASO 3 • SOLUCIÓN GENERAL

Despeje de la Función $T(t)$

Aplicamos exponencial natural base $e$ para obtener la familia de soluciones:

$$T(t) = 22 + C \cdot e^{-0.055t}$$
PASO 4 • SOLUCIÓN PARTICULAR

Evaluación de Condición Inicial

Con $T(0) = 85 \implies 85 = 22 + C \cdot e^0 \implies C = 63$. La solución exacta es:

$$T(t) = 22 + 63 \cdot e^{-0.055t}$$
PASO 5 • TIEMPO CRÍTICO

Umbral Operativo Seguro ($35\text{ }^\circ\text{C}$)

Despejamos $t$ cuando $T(t) = 35\text{ }^\circ\text{C}$ para determinar el tiempo de estabilización:

$$t = -\frac{\ln(13/63)}{0.055} \approx 28.69\text{ min}$$
PASO 6 • MÉTODO NUMÉRICO

Esquema Iterativo de Euler

Aproximación discreta con paso temporal $h$ implementada en software:

$$T_{n+1} = T_n + h \cdot \left[-0.055(T_n - 22)\right]$$

SECCIÓN 04

Implementación Computacional en Python

Arquitectura del Script

Para validar computacionalmente el modelo matemático del artículo, se desarrolló un script en Python 3.11 apoyado en las bibliotecas científicas NumPy y Matplotlib.

  • 1 Cálculo Analítico: Evalúa el logaritmo natural exacto para hallar el minuto en que el servidor alcanza $35\text{ }^\circ\text{C}$.
  • 2 Iteración de Euler: Recorre un arreglo temporal de $0$ a $60\text{ min}$ con paso $h=1\text{ min}$ acumulando pendientes locales.
  • 3 Visualización Científica: Renderiza la curva comparativa lista para informes técnicos.
simulacion_enfriamiento_servidor.py 
import numpy as np
import matplotlib.pyplot as plt

# 1. Parámetros físicos del servidor en el Centro de Datos (CECAR)
T_amb = 22.0      # Temperatura ambiente de la sala (°C)
T_0 = 85.0        # Temperatura inicial tras falla de climatización (°C)
k = 0.055         # Constante de disipación térmica (min^-1)
T_segura = 35.0   # Umbral operativo seguro recomendado ASHRAE (°C)

# 2. Solución Analítica: T(t) = 22 + 63 * exp(-0.055 * t)
t_critico = -np.log((T_segura - T_amb) / (T_0 - T_amb)) / k
print(f"Tiempo requerido para alcanzar {T_segura} °C: {t_critico:.2f} minutos\n")

# 3. Simulación Numérica mediante Método de Euler (paso h = 1 min)
h = 1.0
t = np.arange(0, 61, h)
T_euler = np.zeros_like(t)
T_euler[0] = T_0

for i in range(len(t) - 1):
    dT_dt = -k * (T_euler[i] - T_amb)
    T_euler[i + 1] = T_euler[i] + h * dT_dt

T_analitica = T_amb + (T_0 - T_amb) * np.exp(-k * t)

# 4. Tabla comparativa por consola
print(f"{'Tiempo (min)':<14} | {'Analítica (°C)':<16} | {'Euler (°C)':<14} | {'Error Rel. (%)'}")
print("-" * 65)
for idx in range(0, 61, 5):
    err = abs(T_analitica[idx] - T_euler[idx]) / T_analitica[idx] * 100
    print(f"{t[idx]:<14.0f} | {T_analitica[idx]:<16.2f} | {T_euler[idx]:<14.2f} | {err:.2f}%")

# 5. Gráfica comparativa
plt.figure(figsize=(8, 4.5))
plt.plot(t, T_analitica, 'k-', linewidth=2, label='Solución Analítica (Exacta)')
plt.plot(t[::2], T_euler[::2], 'o--', color='gray', markersize=4, label='Método de Euler (h=1 min)')
plt.axhline(T_segura, color='black', linestyle=':', label=f'Umbral Seguro ({T_segura} °C) -> t = {t_critico:.2f} min')
plt.title('Enfriamiento Térmico de un Servidor en Data Center')
plt.xlabel('Tiempo (minutos)')
plt.ylabel('Temperatura (°C)')
plt.grid(True, linestyle=':', alpha=0.7)
plt.legend()
plt.tight_layout()
plt.show()
SECCIÓN 05

Conclusiones y Referencias Bibliográficas

Conclusiones del Proyecto

Se formuló y resolvió satisfactoriamente un modelo basado en ecuaciones diferenciales ordinarias de primer orden para describir el proceso de enfriamiento de un servidor tras una contingencia térmica, determinando que se requieren 28,69 minutos de refrigeración auxiliar para restablecer la temperatura por debajo del umbral seguro de $35\text{ }^\circ\text{C}$.

La implementación computacional en Python permitió validar la solución analítica mediante el método numérico de Euler con un margen de error relativo inferior al $1,65\%$, evidenciando el valor práctico del cálculo diferencial en la gestión preventiva de centros de datos. Como trabajo futuro, se propone extender el modelo hacia un sistema acoplado de ecuaciones diferenciales que incluya la generación variable de calor según el porcentaje de uso de la CPU.
